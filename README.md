# CrimeZoo
Crime Zoo হলো একটি আধুনিক ক্রাইম রিপোর্টিং ও ফরেনসিক পোর্টাল। এখানে পরিচয় গোপন রেখে বা প্রকাশ করে ছবি, ভিডিও, অডিও ও PDF প্রমাণসহ অপরাধ রিপোর্ট করা যায়। এতে রয়েছে স্বয়ংক্রিয় এআই ডিটেক্টর, অ্যান্টি-কপি ও অ্যান্টি-স্ক্রিনশট সিকিউরিটি, কুইক ভিউ ইমেজ জুম ও স্লাইডশো, ৩২+ জরুরি সরকারি নম্বর, রিপোর্টার ড্যাশবোর্ড এবং টাইম-লক সুরক্ষিত এডমিন প্যানেল।
